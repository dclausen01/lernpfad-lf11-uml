---
titel: Glossar
icon: "📖"
beschreibung: Die wichtigsten UML-Begriffe kurz erklärt – mit englischem Fachbegriff.
reihenfolge: 2
---
| Begriff | Englisch | Erklärung |
| --- | --- | --- |
| Abhängigkeit | dependency | Ein Element benutzt ein anderes kurzzeitig, z. B. als Parameter. |
| Ablaufende | flow final node | Beendet nur den eigenen Zweig einer Aktivität. |
| Aggregation | shared aggregation | Teil-Ganzes-Beziehung; das Teil kann ohne das Ganze existieren. |
| Akteur | actor | Rolle eines Menschen oder externen Systems, das mit dem System interagiert. |
| Aktivierung | execution specification | Balken auf der Lebenslinie: Das Objekt führt gerade etwas aus. |
| Anwendungsfall | use case | Funktion, die das System einem Akteur bietet. |
| Artefakt | artifact | Physische Datei, die auf einem Knoten installiert wird (z. B. `.jar`). |
| Assoziation | association | Strukturelle Beziehung zwischen Klassen („kennt“). |
| Ausführungsumgebung | execution environment | Knoten, der Software ausführt (JVM, Docker, DBMS). |
| Endknoten | activity final node | Beendet die gesamte Aktivität. |
| Erweiterungspunkt | extension point | Stelle in einem Anwendungsfall, an der ein «extend» einhakt. |
| Fragment, kombiniertes | combined fragment | Rahmen im Sequenzdiagramm für `alt`, `opt`, `loop`, `par` … |
| Gabelung / Vereinigung | fork / join | Beginn und Ende paralleler Abläufe (Balken). |
| Generalisierung | generalization | „ist ein“-Beziehung, Vererbung. |
| Guard (Bedingung) | guard | Bedingung in eckigen Klammern, die für einen Weg erfüllt sein muss. |
| Interface (Schnittstelle) | interface | Sammlung von Methodensignaturen, die Klassen realisieren. |
| Knoten | node | Hardware oder Ausführungsumgebung im Verteilungsdiagramm (Quader). |
| Komponente | component | Austauschbarer Softwarebaustein mit Schnittstellen. |
| Komposition | composite aggregation | Starke Teil-Ganzes-Beziehung; das Teil lebt und stirbt mit dem Ganzen. |
| Lebenslinie | lifeline | Senkrechte gestrichelte Linie eines Objekts im Sequenzdiagramm. |
| Link | link | Verbindung zwischen zwei Objekten – die „Instanz“ einer Assoziation. |
| Multiplizität | multiplicity | Anzahl der beteiligten Objekte an einem Beziehungsende (`0..*`). |
| Nachricht, synchrone / asynchrone | synchronous / asynchronous message | Mit bzw. ohne Warten auf die Antwort. |
| Navigierbarkeit | navigability | Pfeilspitze: Von hier aus kann man das andere Objekt erreichen. |
| Objektknoten | object node | Daten oder Dokument im Aktivitätsdiagramm (eckiges Rechteck). |
| OMG | Object Management Group | Konsortium, das den UML-Standard herausgibt. |
| Partition | activity partition (swimlane) | Bahn für einen Verantwortlichen im Aktivitätsdiagramm. |
| Realisierung | realization | Eine Klasse setzt ein Interface um (`implements`). |
| Rollenname | role name | Name eines Assoziationsendes; im Code meist der Attributname. |
| Sichtbarkeit | visibility | Zugriffsrecht: `+` public, `-` private, `#` protected, `~` package. |
| Stereotyp / Schlüsselwort | stereotype / keyword | Text in « », der ein Element genauer kennzeichnet (`«interface»`). |
| Strukturdiagramm | structure diagram | Zeigt den statischen Aufbau (z. B. Klassendiagramm). |
| Systemgrenze | subject (system boundary) | Rahmen um alle Anwendungsfälle des betrachteten Systems. |
| Transition | transition | Zustandswechsel, beschriftet mit `ereignis [bedingung] / aktion`. |
| Verhaltensdiagramm | behavior diagram | Zeigt Abläufe und Reaktionen über die Zeit. |
| Zustand | state | Situation eines Objekts, die eine Zeit lang andauert. |
